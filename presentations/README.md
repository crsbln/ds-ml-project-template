## How to present

- **PowerPoint:** open the `.pptx`, *Slide Show → From Beginning* (F5), tick *Use Presenter View* to read the speaker notes on your own screen.
- **Google Slides:** upload the `.pptx` to Drive, open with Google Slides, *Slideshow → Presenter view*.
- **Keynote:** open the `.pptx` directly.
- **No software:** use the PDF.

Every chart is a native chart (right-click → *Edit Data*). Every slide has speaker notes written to be read aloud.

## Technical deck (25 slides)

Same business look as the client deck. Overview (summary, framing) · Data (cleaning, target, removing the future data: 99.7%) · Exploration (goal, category, length within goal, round numbers, years) · Modelling (features, baseline, model comparison incl. the goal rule, tuning) · Evaluation (test results, calibration, time drift, error analysis, importance, why no what-if) · Wrap-up (two approaches, limitations & constraints, reproduce, thank you).

## Rebuild

The decks are generated by `build/` (Node.js 18+, [pptxgenjs](https://gitbrent.github.io/PptxGenJS/)) from `../reports/results.json`:

```bash
cd presentations/build
npm install
npm run build            # both decks; or: node build_decks.js client
```

Design system (both decks use the `business` theme: white slides, Kickstarter-style green, charcoal; layouts, the "funding bar" motif) lives in `build/lib.js`; each deck's slides in `build/client.js` and `build/technical.js`. Export to PDF with PowerPoint (*File → Export*) or LibreOffice (`soffice --headless --convert-to pdf *.pptx`).
